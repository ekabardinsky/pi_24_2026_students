# Шпаргалка по UML-диаграммам классов в Mermaid

Чтобы ваши диаграммы прошли автоматическую проверку AI-агентом, все связи между классами должны быть указаны **семантически верно**. Использовать обычную стрелочку `-->` для всего подряд — это ошибка.

### 1. Наследование (Inheritance)
* **Смысл:** Отношение «является» (IS-A). Родителю передаются общие свойства.
* **Пример:** `Автомобиль` является `ТранспортнымСредством`.
* **Код в Mermaid:** `Родитель <|-- Наследник`

### 2. Реализация интерфейса (Realization)
* **Смысл:** Класс обязуется реализовать методы интерфейса.
* **Пример:** Класс `Document` реализует интерфейс `IPrintable`.
* **Код в Mermaid:** `Интерфейс <|.. Класс`

### 3. Композиция (Composition)
* **Смысл:** Жесткая связь «часть-целое». Часть **не может** существовать без целого. Если уничтожить целое, уничтожатся и части.
* **Пример:** `Университет *-- Факультет`. (Закроется вуз — не станет и факультетов).
* **Код в Mermaid:** `Целое *-- Часть` (закрашенный ромб у Целого)

### 4. Агрегация (Aggregation)
* **Смысл:** Мягкая связь «часть-целое». Части **могут** существовать сами по себе. Объекты создаются снаружи и передаются в класс через конструктор/методы.
* **Пример:** `Университет o-- Профессор`. (Если вуз закроется, профессор уйдет в другой университет).
* **Код в Mermaid:** `Целое o-- Часть` (пустой ромб у Целого)

### 5. Ассоциация (Association)
* **Смысл:** Обычная связь. Один класс знает о другом (хранит ссылку в виде поля), но они не образуют «целое-часть».
* **Пример:** `Студент --> Книга` (у студента в поле хранится ссылка на книгу).
* **Код в Mermaid:** `КлассА --> КлассБ`

### 6. Зависимость (Dependency)
* **Смысл:** Самая слабая связь «использует». Постоянного поля со ссылкой нет. Объект просто передается как параметр в метод или создается внутри метода локально.
* **Пример:** `ReportGenerator ..> ConsolePrinter` (принтер нужен только на время работы метода Print).
* **Код в Mermaid:** `КлассА ..> КлассБ` (пунктирная стрелка)

---
💡 **Важно:** Проверяйте синтаксис в VS Code через плагин Mermaid Preview перед тем, как делать коммит. Если на GitHub в браузере вместо диаграммы отображается ошибка кода — автоматика ее не засчитает.
